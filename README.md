# i重TV

## 责任边界与使用声明

本项目仅用于接口学习、安全研究、请求构造分析和推动签到系统完善。请勿将本项目用于违反学校规定、侵犯他人账号权益、批量滥用、代签到或任何未授权场景。

本项目不提供在线服务，不收集 token，不保存个人信息，不中转任何请求，也不提供技术支持。使用者应仅在本人账号、本机环境和合规授权范围内使用，并自行承担账号、合规和行为后果风险。

token 属于个人敏感凭据。请勿上传、分享或交给他人。

## 项目简介

i重TV 是一个本地研究工具集合，用于理解 i重科小程序中课程列表和签到请求的构造方式。

项目包含：

- 静态 HTML 请求构造工具：在浏览器本地填写 token、课程、签到码和位置，构造并发送请求。
- Windows 本地 token 辅助提取脚本：在电脑微信已登录并打开目标小程序后，从本机相关进程中尝试寻找当前登录 token。

所有核心操作均在使用者本机完成。作者不参与请求过程。

## 项目文件

- `wx96_checkin_tool.html`：单文件静态 HTML 工具。
- `双击运行_获取token.cmd`：Windows 本地 token 提取辅助脚本。

## 使用方法

### 使用静态 HTML

1. 下载 `wx96_checkin_tool.html`。
2. 使用浏览器在本机打开该文件。
3. 填入自己的 token。
4. 页面会尝试自动获取课程列表。
5. 选择课程，填写 6 位签到码。
6. 通过地图选择位置，或手动填写经纬度。
7. 点击 `发送签到请求`。

页面也提供复制 JSON 和 curl 的功能，便于学习请求结构。

多账号模式下，可点击 `添加 token` 增加 token 输入栏。发送签到请求时，页面会对所有已填写 token 分别发起请求，并在输出区显示每个账号的结果。

### 使用本地 token 提取脚本

1. 在电脑微信中打开目标小程序，并保持登录状态。
2. 双击运行 `双击运行_获取token.cmd`。
3. 脚本会在本机扫描相关电脑微信小程序进程，尝试寻找当前登录 token。
4. 成功后，窗口会显示 token、有效期和课程数量。
5. 窗口会停留，便于复制 token。

该脚本仅适用于 Windows 电脑微信环境。请勿用于他人账号或未授权设备。

## 数据与隐私说明

- 本项目没有后端服务器。
- HTML 页面中的请求由浏览器直接发送到目标接口。
- 作者不会收到 token、课程、位置或请求内容。
- HTML 页面可能使用浏览器 `localStorage` 保存 token、位置和页面设置，便于下次本地打开继续使用。
- 如果需要清除本地保存内容，可在浏览器站点数据中清除该页面对应的本地存储。
- CMD 脚本默认只在窗口显示 token，不在项目目录生成 token 文件。

## 适用范围与限制

本项目依赖当前接口行为和电脑微信运行状态，可能随系统更新而失效。

已知限制包括：

- token 有有效期，过期后需要重新获取。
- 浏览器请求可能受 CORS、网络环境、DNS 或校园网出口影响。
- 手机浏览器定位通常要求 HTTPS 页面，直接打开本地 HTML 时可能无法触发定位权限。
- 地图瓦片依赖外部地图资源，网络异常时可能无法加载底图。
- 电脑微信脚本依赖本机进程状态，不保证每次都能找到 token。
- 后端接口、字段、校验逻辑变化后，工具可能需要调整。

## 对系统维护方的改进建议

如果签到接口仅依赖 token、签到码和前端传入位置，相关请求较容易被复现。建议系统维护方从服务端加强校验，而不是依赖前端代码隐藏逻辑。

建议方向：

- token 与设备、会话、风险特征绑定。
- 缩短签到码有效期，并增加一次性使用校验。
- 服务端校验签到状态、课程状态、时间窗口和账号权限。
- 增加异常位置、异常请求频率、多账号集中请求等风控检测。
- 对关键接口增加审计日志和告警。
- 避免敏感凭据在前端环境中长时间可复用。
- 对位置可信度进行多维校验，不应只信任前端上传的经纬度字符串。

## 常见问题

### 为什么不提供在线页面？

为了避免收集、中转或托管任何用户数据，也避免被误解为服务化工具。本项目建议下载到本地后使用。

### token 会上传给作者吗？

不会。本项目没有服务器。HTML 页面在本地运行，请求直接由浏览器发往目标接口。

### 为什么获取课程列表失败？

常见原因包括 token 过期、网络不可达、CORS 失败、校园网出口差异、DNS 问题或接口变化。

### 为什么手机定位不可用？

浏览器定位通常要求 HTTPS 或 localhost。本地文件、普通 HTTP 局域网页面或部分手机浏览器可能不会弹出定位权限。可改用地图点选或手动填写经纬度。

### 可以用于他人账号吗？

不可以。请仅在本人账号和合规授权范围内使用。
